使用指南

把你的 Agent 连起来。

准备好已安装并登录的编程 Agent，再选择一条适合你的路径。以下命令在你的终端执行。

01

全新安装

先安装，再创建配置并替换 REPLACE 占位值。doctor 检查配置与依赖，不建立平台连接。

npm install -g cc-connect-next
cc-connect-next
cc-connect-next doctor
阅读完整指南
02

接入飞书

交互式配置飞书机器人与工作区，可选择绑定官方 lark-cli。配置完成后运行 doctor，再启动服务。

cc-connect-next feishu setup
cc-connect-next doctor
cc-connect-next
阅读完整指南
03

先评估迁移，再切换服务

dry-run 只报告计划。实际 migrate --switch 会切换服务运行与自启动状态；先阅读安装文档中的备份、兼容性和回滚说明。

cc-connect-next migrate --dry-run
阅读完整指南

接着了解

聊天命令与日常使用 完整配置参考 Agent 能力与权限 问题反馈
cc connect next

本地执行，随处连接。
