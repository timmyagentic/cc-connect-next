手动安装，按这五步走。

01

先准备可用的 Agent

安装并登录一个受支持的 Agent CLI，确认它能在本机回答；选择真实存在的项目目录，并记下绝对路径。还没有 Agent 时先完成它的安装与登录。

02

安装并填写配置

以下命令以 macOS / Linux 的默认配置路径为例；Windows 请使用对应的绝对路径。首次运行生成模板后退出是正常行为。填写真实 work_dir、Agent 类型和项目名，并替换所有 REPLACE 占位值；后续始终使用同一个配置文件。

npm install -g cc-connect-next
cc-connect-next --config ~/.cc-connect-next/config.toml
查看完整首次安装说明
03

接入飞书

使用配置里的同一项目名完成机器人设置与扫码，可选择官方 lark-cli companion。feishu setup 配置机器人，不会替已有项目填写 work_dir。

cc-connect-next feishu setup --config ~/.cc-connect-next/config.toml
阅读完整指南
04

前台启动，收到真实回复

doctor 只检查环境，不连接平台。通过后前台启动，在机器人私聊发送 /version、/whoami 和一条普通提问，确认 Agent 回答；按实际用户 ID 设置访问范围。

cc-connect-next doctor --config ~/.cc-connect-next/config.toml
cc-connect-next --config ~/.cc-connect-next/config.toml
05

转到后台，再验证一次

先停止本次启动的前台进程，再安装后台服务。核对服务、Runtime 和平台就绪状态，然后再次发送普通提问，确认关闭终端后仍能回答。

cc-connect-next daemon install --config ~/.cc-connect-next/config.toml
cc-connect-next daemon status

已有官方 CC Connect？

先评估迁移，再切换服务

dry-run 只报告计划。实际 migrate --switch 会切换服务运行与自启动状态；先阅读安装文档中的备份、兼容性和回滚说明。

cc-connect-next migrate --dry-run
