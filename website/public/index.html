还有几个常见问题。

官网会连接我的电脑吗？

不会。官网提供介绍、交互示例与安装说明。实际连接由你在自己机器上安装和配置的 CC Connect Next 完成。

需要公网 IP 吗？

飞书使用 WebSocket 长连接，不需要公网 IP、域名或证书。其他平台的接入要求见对应指南。

数据会发往哪里？

执行环境在本地；消息经过所选聊天平台，Agent 请求会发往其配置的服务提供方。本地执行并不代表完全离线。

CC Connect Next 免费吗？

代码采用 MIT 许可。Agent 订阅、模型 API 与聊天平台可能产生各自的费用。
