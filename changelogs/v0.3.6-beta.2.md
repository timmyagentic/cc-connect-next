# cc-connect-next v0.3.6-beta.2

## 中文

- 飞书绑定用户的私聊表单卡片可在原卡片返回所提交的文本及 HMAC-SHA256 回执；保留原始空白、换行和支持的 emoji，不执行命令或触发 Agent 回合。
- 校验项目、用户、字段与 nonce，限制为 1,000 个 Unicode 字符，拒绝无效或不可见输入。通过 `direct_user_form_receipts` 能力声明识别支持情况；旧命令按钮行为保持兼容。
- 详见 [PR #214](https://github.com/timmyagentic/cc-connect-next/pull/214) 和飞书卡片契约。真实飞书 WebSocket 提交未在本次发布验证中执行。
- Beta 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.5。

## English

- Return the submitted text and an HMAC-SHA256 receipt on the originating owner-bound Feishu private form card. Preserve exact whitespace, line endings and supported emoji without dispatching a command or Agent turn.
- Validate project, operator, field and nonce bindings; accept up to 1,000 Unicode code points and reject invalid or invisible input. Discover support through `direct_user_form_receipts`; preserve legacy command-button behavior.
- See [PR #214](https://github.com/timmyagentic/cc-connect-next/pull/214) and the Feishu card contract. Live Feishu WebSocket submission was not exercised during this release verification.
- Install with `npm install -g cc-connect-next@beta`. Stable channels remain on v0.3.5.
