# cc-connect-next v0.3.5-beta.11

## 中文

- 聊天模型统一保存在对应项目的 `[[projects.chat_models]]` 配置中。`/model <name>` 与 `/model reset` 直接保存到 config.toml；手工编辑或删除后可用 `/config reload` 加载整表。
- 保存和热加载按同一锁顺序发布设置，避免旧快照覆盖新选择。正在回复的回合保持原模型，后续及排队回合使用新设置；保存失败保留运行中的绑定。
- 启动时迁移状态文件中仍存在的 `group_model_bindings` / `chat_model_bindings`，显式 TOML 配置优先。先成功写入配置，再清理旧模型字段；迁移失败停止启动并保留可恢复数据。兼容旧聊天身份元数据。
- 迁移无法恢复已被旧版本删除的数据；工作区默认值不会转换为聊天绑定。降级前保留配置和状态备份，旧版本不读取新的 chat_models 配置。
- 保留暂不可用的平台、Provider 和 Agent 身份；受影响聊天明确报错，不静默切换 Provider 或回退默认模型。推理强度和目录状态继续沿用原存储。
- 验证边界：自动化验证覆盖配置保存、迁移、热加载并发和排队回合；真实平台交互及付费模型请求未执行。
- Beta 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.4。

## English

- Store chat model selections in each project's `[[projects.chat_models]]` configuration. `/model <name>` and `/model reset` persist directly to config.toml; `/config reload` replaces the table after manual edits or deletions.
- Serialize save/reload publication to prevent stale snapshots from replacing newer choices. Running replies retain their model; subsequent and queued turns use the new settings. Failed saves retain the running bindings.
- On startup, migrate remaining `group_model_bindings` / `chat_model_bindings` from project state, with explicit TOML entries taking precedence. Save configuration before clearing legacy model fields; failed migration stops startup and preserves recoverable data. Legacy verified chat metadata is supported.
- Migration cannot recover data already deleted by an older version, and workspace defaults are not converted into chat bindings. Keep configuration and state backups before downgrading: older versions do not read chat_models.
- Preserve dormant platform, Provider and Agent identities; affected chats fail explicitly without silently switching providers or falling back to defaults. Reasoning and directory state retain their existing storage.
- Verification boundaries: automated coverage includes configuration persistence, migration, concurrent reloads and queued turns. Live platform interactions and paid model requests were not exercised.
- Install with `npm install -g cc-connect-next@beta`. Stable channels remain on v0.3.4.
