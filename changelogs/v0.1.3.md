# cc-connect-next v0.1.3

## 中文

这是基于最新 `main` 的稳定版。三项交付：daemon 侧的新版本主动提醒（从此老版本用户不再错过更新）、移植上游 v1.5.0 的两个 P1 稳定性修复、以及全面重构的双语 README。

### 变化

- **新版本主动提醒。** 此前所有更新入口都是"用户主动问"（`/upgrade`、`check-update`、CLI 帮助页提示），跑着旧版 daemon 的用户永远不知道新版本已发布。现在 daemon 启动 2 分钟后、以及之后每 24 小时检查一次最新稳定版；发现新版本时，向每个项目最近活跃的会话发送一条本地化提醒（指引 `/upgrade` / `/upgrade confirm`）。每个版本对每个项目**终生只提醒一次**，状态跨重启持久化，绝不重复打扰；暂时无法送达的项目会在下个周期重试。配置 `update_notice = false` 可关闭（默认开启）。
- **移植上游 #1693 P1 稳定性修复。** 其一：重启通知派发协程补上 defer recover，平台适配器 panic 不再能杀死整个 daemon（回归测试可复现修复前的崩溃）。其二：非图片消息进入引擎前先冲刷该会话缓冲中的图片批，修复"图片+文本在攒批窗口内速发时，缓冲图片被消息水位线判旧丢弃"的丢图缺陷。第三个 P1（idle-close 竞态）不适用于本项目，已在审计文档记录。
- **README 全面重构。** 中英双语对齐高星项目版式：横幅与徽章、特性亮点、卡片生命周期与 steer 交接的矢量示意图、快速开始、排队 vs steer 对比表、Agent/平台矩阵、与官方 CC Connect 的对比表、文档索引。迁移与共存的契约级完整文本原样迁至 `docs/migration.md` / `docs/migration.zh-CN.md`，一字未删。
- **审计推进。** 上游审计基线推进至 v1.5.0 正式版；beta.3 → v1.5.0 增量的全部分类决策记录在审计文档中。

### 升级

稳定版用户可以直接更新或重新安装：

```bash
cc-connect-next update
# 或
npm install -g cc-connect-next
```

升级到本版本后，未来的每个新稳定版都会主动提醒你，无需再关注发布页。

## English

This is a stable release built from the latest `main`. Three deliveries: a
daemon-side proactive update notice (old-version users will never miss a
release again), the two applicable upstream v1.5.0 P1 stability fixes, and a
fully rebuilt bilingual README.

### Changes

- **Proactive update notice.** Every update surface used to be pull-only
  (`/upgrade`, `check-update`, the CLI usage hint), so a user running an old
  daemon never learned a newer version existed. The daemon now checks for the
  newest stable release 2 minutes after startup and every 24 hours, and sends
  each project's most recently active chat one localized notice per version
  (pointing at `/upgrade` / `/upgrade confirm`). Each version is announced at
  most **once per project, ever** — state persists across restarts — and
  unreachable projects are retried on the next cycle. Disable with
  `update_notice = false` (default on).
- **Upstream #1693 P1 stability fixes ported.** First, the restart-notify
  dispatch goroutine gains a defer-recover so a platform adapter panic can no
  longer kill the daemon (the regression test reproduces the pre-fix crash).
  Second, a session's pending image batch is flushed before any non-image
  message reaches the engine, fixing the dropped-image defect when an image
  and a text arrived within the batching window. The third P1 (idle-close
  race) does not apply to this project and is recorded in the audit log.
- **README overhaul.** Both languages rebuilt in the style of high-star
  projects: banner and badges, feature highlights, a vector diagram of the
  card lifecycle and steer handoff, quick start, a queue-vs-steer table, the
  agents/platforms matrix, an upstream comparison table, and a documentation
  index. The contractual migration/coexistence text moved verbatim to
  `docs/migration.md` / `docs/migration.zh-CN.md` — nothing was cut.
- **Audit advanced.** The upstream audit baseline moves to v1.5.0 final, with
  every beta.3 → v1.5.0 delta classified in the audit document.

### Upgrade

Stable users can update or reinstall directly:

```bash
cc-connect-next update
# or
npm install -g cc-connect-next
```

From this version on, every future stable release announces itself — no need
to watch the releases page.
