# cc-connect-next v0.3.6-beta.6

## 中文

- 飞书 Card 2.0 的表单回执和文字/表情确认在回调时保留 2.0 卡片结构。按钮显式绑定 `cc_card_schema: "2.0"` 后，回执不再被改写成 Card 1.0，避免飞书拒绝更新（`200830: schemaV2 card can not change schemaV1`）。
- 未提供该字段时仍使用 Card 1.0。其他显式值在替换卡片或派发命令前拒绝。提交原文、HMAC、准入检查和原命令只派发一次，均保持不变。
- 详见 [PR #220](https://github.com/timmyagentic/cc-connect-next/pull/220)。本次发布未再次实测真实飞书群和运行中的 daemon 升级。
- 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.5。

## English

- Keep Feishu Card 2.0 form receipts and text/reaction confirmations on schema 2.0. An explicit callback value `cc_card_schema: "2.0"` prevents the receipt from being rewritten as Card 1.0, which Feishu rejects with `200830: schemaV2 card can not change schemaV1`.
- Omitting the value keeps Card 1.0. Any other explicit value is rejected before card replacement or command dispatch. Submitted text, HMAC, admission checks, and the single original command dispatch stay unchanged.
- See [PR #220](https://github.com/timmyagentic/cc-connect-next/pull/220). Live Feishu groups and running daemon upgrades were not exercised again for this release.
- Install with `npm install -g cc-connect-next@beta`. Stable remains v0.3.5.
