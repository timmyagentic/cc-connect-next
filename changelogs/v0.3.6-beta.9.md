# cc-connect-next v0.3.6-beta.9

## 中文

- 修复 npm 安装器在下载、校验并安装二进制后仍不退出的问题：跟随 HTTP 重定向时消费中间响应，让 keep-alive 连接及时释放。下载地址与 SHA-256 校验规则保持不变。
- 新增真实本地 HTTP keep-alive 重定向回归，检查下载完成后 Node 子进程能自然退出；旧实现会下载成功但持续占用连接。
- 其余功能与 [v0.3.6-beta.8](https://github.com/timmyagentic/cc-connect-next/releases/tag/v0.3.6-beta.8) 一致。未重新验收真实飞书群或运行中的 daemon 升级。
- 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.5。

## English

- Fix the npm installer remaining alive after downloading, verifying, and installing the binary. Consume intermediate HTTP redirect responses so keep-alive connections can be released. Download destinations and SHA-256 verification rules are unchanged.
- Add a real local HTTP keep-alive redirect regression that verifies the downloader subprocess exits naturally after completion; the previous implementation downloaded successfully but retained a connection.
- Other features are unchanged from [v0.3.6-beta.8](https://github.com/timmyagentic/cc-connect-next/releases/tag/v0.3.6-beta.8). Live Feishu groups and running daemon upgrades were not exercised again.
- Install with `npm install -g cc-connect-next@beta`. Stable remains v0.3.5.
