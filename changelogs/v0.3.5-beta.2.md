# cc-connect-next v0.3.5-beta.2

## 中文

### 更新亮点

- 飞书和 Lark 支持在同一群、同一真实话题内补读指定机器人的公开答复，切换机器人时可以接续近期讨论。使用 `group_context_include_peer_bots = true` 显式开启，并通过 `peer_bots` 配置对端 app ID 和别名。
- 共享背景保留机器人身份、卡片标题及进行中、失败等状态；流式卡片更新为最终答复后可以再次补读，内容改回旧版本时也能正确识别。机器人消息不会触发自动互聊。
- 修复 `group_context` 与无需 @ 回复规则的配置互斥；已配置自动回复的群可以同时补读近期背景。
- 完善网站首次安装指南。

### 使用说明

- 对端共享默认关闭。为两个机器人分别开启时，`peer_bots` 中填写另一机器人的 app ID；修改配置后重启服务。
- 默认范围为触发消息前 30 分钟内创建的最近 20 条消息，完整背景最多 8,000 字符。不同群、不同真实话题及私聊保持隔离；各机器人的原生 Agent 会话独立。
- 窗口外创建的卡片不补读；触发后才更新的卡片快照会跳过并提示背景不完整，后续用户触发时再读取。仅使用已有历史读取权限，不下载背景附件。
- 本版为 Beta；npm `beta` 更新到本版，GitHub Latest 和 npm `latest` 继续保持稳定版本。

```sh
npm install -g cc-connect-next@beta
cc-connect-next --version
```

## English

### Highlights

- Feishu and Lark can include selected peer bots' public replies as recent background within the same group and real topic. Explicitly enable `group_context_include_peer_bots = true` and configure peer app IDs and aliases in `peer_bots`.
- Shared snapshots retain sender attribution, card titles and in-progress or failed states. Edited streaming cards can deliver their final answer on a later turn, including edits that restore an earlier version. Bot messages do not trigger automatic bot-to-bot reply loops.
- Group context now works with configured mention-free reply rules.
- The website's first-install guide is more complete.

### Usage notes

- Peer sharing is off by default. Configure each bot with the other bot's app ID and restart after changing configuration.
- Defaults remain 30 minutes by message creation time, 20 messages and 8,000 characters including attribution. Groups, real topics and private conversations remain isolated; native Agent sessions stay independent.
- Cards created outside the window are excluded. Snapshots edited after the user trigger are skipped with an incomplete-context notice and can be read on a later trigger. Existing history access is used without downloading background attachments.
- This is a beta release. npm `beta` advances to this version; GitHub Latest and npm `latest` continue serving the stable release.

Install with `npm install -g cc-connect-next@beta` or `cc-connect-next update beta`.
