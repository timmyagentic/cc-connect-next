# cc-connect-next v0.3.5-beta.5

## 中文

### 更新亮点

- 支持群聊独立绑定推理强度，并统一为 `/model chat` 与 `/reasoning chat`；`group` 子命令和 `/effort` 保持兼容。
- 私聊按已验证用户和项目隔离模型及推理强度，跨新会话与重启保留；模型与强度可独立重置，不修改其他聊天默认值。
- 每个新回合分别解析模型与强度，显式单次设置优先；排队请求读取最新绑定，当前回复保持原设置。
- 修复飞书/Lark 私聊话题、图片批次和设置卡片的身份传递，拒绝其他用户操作所属私聊设置卡片。

### 验证与使用

- 包含聊天隔离、持久化、独立重置、回合优先级、卡片发送与回调的回归测试。
- 真实飞书消息与付费模型调用未执行；正式构建与发布由版本 tag 的 CI 和 Release 流水线验证。
- 本版为 Beta，稳定渠道保持 v0.3.4。
- 安装：`npm install -g cc-connect-next@beta`；更新：`cc-connect-next update beta`。

## English

### Highlights

- Pin independent group reasoning effort through `/reasoning chat`; `/model chat`, the legacy `group` subcommands and `/effort` remain compatible.
- Isolate private-chat model and effort settings by verified user and project. Persist settings across sessions and restarts, and reset each field independently.
- Resolve each field per turn with explicit one-shot overrides taking precedence. Queued requests use the latest bindings without changing an active reply.
- Preserve verified identity in Feishu/Lark private threads, image batches and settings cards; reject another user's operation on a private settings card.

### Verification and usage

- Includes regression coverage for chat isolation, persistence, independent resets, turn precedence, emitted cards and callbacks.
- Live Feishu delivery and paid model calls were not executed. Release-tag CI and Release workflows validate the production build and publication.
- This is a beta release; stable channels remain on v0.3.4.
- Install with `npm install -g cc-connect-next@beta` or update with `cc-connect-next update beta`.
