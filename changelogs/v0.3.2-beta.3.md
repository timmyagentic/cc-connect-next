# cc-connect-next v0.3.2-beta.3

## 中文

本次 Beta 合并 PR #158、#159、#160、#161，改进诊断和飞书消息处理可靠性。

- macOS doctor 同时显示 Agent CLI 路径与版本，并展示有时限和深度限制的诊断进程祖先。屏幕录制、辅助功能与 Apple Events 权限明确标为未探测，不把终端检查当作 daemon 权限证明。
- 定时 shell 失败会保留退出码及脱敏诊断尾部，区分取消与超时，静默任务仍不发送聊天输出。检测到凭据命令行参数时省略整段输出，防止 shell trace 的多行或拼接密码进入持久化错误和日志。
- 重启通知遇到飞书明确的永久投递错误（机器人不在聊天中）立即结束重试；服务取消会中断退避等待，其他错误继续有界重试。
- 飞书同会话的附件下载和分发按接收顺序进行，后来的文字不会越过下载中的图片，过期的批次定时器不会提前冲刷新批次。用户名和群名查询支持取消，并各自最多等待两秒，失败时使用 ID；不同会话仍可并行。

升级 Beta：

```sh
npm install -g cc-connect-next@beta
cc-connect-next --version
```

Stable 与 npm `latest` 保持 v0.3.1。发布不会自动升级或重启本机服务。真实飞书/Lark 端到端投递和各平台原生运行仍须分别验收；自动化测试不等于真实客户端验收。

## English

This beta merges PRs #158–#161, improving diagnostics and Feishu delivery reliability.

- macOS doctor retains the Agent CLI path and version and reports bounded diagnostic process ancestry. Screen Recording, Accessibility, and Apple Events remain explicitly unprobed; terminal checks do not prove daemon permissions.
- Failed scheduled shell jobs retain the exit code and a redacted diagnostic tail, distinguish cancellation from timeout, and keep muted chat delivery silent. Output containing credential-bearing CLI flags is omitted entirely to avoid persisting multiline or concatenated shell-trace secrets.
- Restart notices stop retrying Feishu permanent rejection when the bot is outside the destination chat. Service cancellation interrupts backoff; other errors keep bounded retries.
- Feishu serializes attachment handling and dispatch within a session. Later text cannot overtake an image download, and stale batch timers cannot flush a reset batch early. User/chat name lookups honor cancellation and have a two-second timeout each, falling back to IDs; other sessions remain independent.

Install with `npm install -g cc-connect-next@beta`. Stable and npm `latest` remain v0.3.1. Publication does not upgrade or restart local services. Real Feishu/Lark end-to-end delivery and native execution on each platform require separate acceptance; automated checks do not establish those results.
