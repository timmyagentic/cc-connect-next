# cc-connect-next v0.3.7-beta.2

## 中文

修复 beta.1 候选构建的两项 lint 问题后发布。beta.1 未发布到 GitHub Release/npm，标签保留；此次仅简化嵌入字段选择器并检查测试清理错误，不改变后端行为。

在 v0.3.6 稳定版基础上合并 #240，新增隔离 Cron 任务的后端选择能力。

- Prompt Cron 可设置 `backend=exec` 或 `backend=app_server`，普通聊天继续使用项目配置的后端。省略或清空时继承项目默认值。
- 显式覆盖仅适用于有效会话模式为 `new_per_run` 的任务，避免更改正在进行的普通聊天。Shell 任务、不支持此能力的 Agent 和无效后端会被拒绝。
- CLI、local / management API、Agent 能力清单和 Web 编辑器均支持此字段。Web 选择后端时会将任务设为每次新建会话。
- 后端选择使用单次任务适配器，沿用现有会话启动路径及 Provider、凭据、模型配置和历史处理；不修改项目默认值。本版本不调整临时会话或保留策略。

### 使用与验证

`cc-connect-next cron add --cron "0 6 * * *" --prompt "Daily report" --session-mode new-per-run --backend exec`

`cc-connect-next cron edit <job-id> backend ""` 恢复后端继承；会话模式仍独立管理。

安装测试版：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.6。已有任务省略新字段时行为不变。

本地验证包含 Web 构建、Cron Web 测试、Core/Codex 后端与 CUJ 测试、Go build/vet；本地 CLI Unix socket 测试受环境限制。标签发布流水线执行完整自动化测试、签名、六平台产物与公开下载校验。本次发布操作未执行真实付费 Cron 或运行中 daemon 升级验收。

## English

This release corrects two lint findings from the beta.1 candidate, which was not published to GitHub Releases or npm; its tag remains. The fixes simplify an embedded selector and check test cleanup errors without changing backend behavior.

Built on stable v0.3.6, this beta incorporates #240 and adds backend selection for isolated Cron tasks.

- Prompt Cron jobs can select `backend=exec` or `backend=app_server` while ordinary chat retains the project backend. Omitted or cleared values inherit the project default.
- Explicit overrides require effective `new_per_run` session mode, preventing a task from changing an ongoing ordinary conversation. Shell jobs, unsupported Agents and invalid backends are rejected.
- The CLI, local and management APIs, Agent capability manifest and Web editor expose the field. Selecting a backend in the Web editor sets the task to start a new session on each run.
- A task-scoped adapter retains the existing session startup path, including Provider, credentials, model configuration and history handling, without changing project defaults. Ephemeral-session and retention policies are unchanged.

### Usage and verification

`cc-connect-next cron add --cron "0 6 * * *" --prompt "Daily report" --session-mode new-per-run --backend exec`

`cc-connect-next cron edit <job-id> backend ""` restores backend inheritance; session mode remains independently managed.

Install with `npm install -g cc-connect-next@beta`. The stable channel remains v0.3.6. Existing jobs without the new field retain their behavior.

Local verification covered the Web build, Cron Web tests, Core/Codex backend and CUJ tests, and Go build/vet. Local CLI Unix socket tests were environment-limited. Tag publication runs full automated checks, signing, six-platform artifact validation and public-download checks. Live paid Cron and running daemon upgrade acceptance were not performed during this release operation.
