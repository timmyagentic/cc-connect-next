# cc-connect-next v0.3.6-beta.12

## 中文

- 修复普通飞书按钮无法触发命名 Hook 的问题。普通按钮回调省略组件 name，现在支持在按钮 value 中显式配置 `hook_action`。表单提交继续支持通过组件名称提供动作名。
- 补充模拟真实普通按钮回调的回归测试，并说明同一卡片的组件名称需保持唯一。
- 安装 `npm install -g cc-connect-next@beta`。

## English

- Fix named hooks for ordinary Feishu buttons, whose callbacks omit component names. Set `hook_action` in the button value to supply an explicit action name. Form-submit buttons can continue using their component name.
- Add regression coverage matching ordinary button callbacks and document unique component names within a card.
- Install with `npm install -g cc-connect-next@beta`.
