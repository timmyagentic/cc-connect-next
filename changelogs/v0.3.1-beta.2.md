# cc-connect-next v0.3.1-beta.2

## 中文

此 Beta 完整适配此前审计选出的 14 项官方修复，保留 Next 的权限、引用附件、
工作区、单卡和忙时消息处理规则。Stable 仍为 v0.3.0。

- 飞书卡片回调统一校验操作者 allow_from；富文本新附件可与已获准的引用附件同时传递。
- 飞书文件、图片和音频支持有界 Range 下载，核对范围和长度，支持取消和瞬态重试。
- Codex stdio 不再传 --listen；支持 CODEX_CLI_PATH 和 macOS ChatGPT/Codex 当前及旧版内置 CLI，显式 cmd 优先且错误配置不会静默回落。
- 修复 idle reset 换锁、失败回合后续接 ID 保存、工作区切换 Agent 后的不兼容 ID 清理。历史保留。
- Claude 自动批准模式仍保留用户提问；卡片单选使用平铺操作行。
- Stop hook 拒稿不再拼入最终回复。Claude 管道等待、强杀确认有时限，并能解除阻塞的输入写入；主动停止使用短等待，正常清理保留 Hook 时间。关闭期间阻止同一会话重建；关闭失败后避免自动续接旧会话。
- launchd 已加载服务原地重启并保留当前域；Cron 按任务自身时区显示。
- 删除其余会话 Token/context 采集及零值日志；独立账户额度查询 /usage 保留。

### 安装

```bash
npm install -g cc-connect-next@beta
cc-connect-next --version
```

也可使用 `cc-connect-next update beta`；在聊天中使用 `/upgrade beta`。安装与正式服务加载是独立步骤。默认 Stable 渠道及 npm latest 不变。无需为这些修复增加新的必填配置或扩大飞书权限。

原生 Windows 进程运行与真实飞书手机点击/大附件端到端验收以实际验证记录为准，模拟测试不能替代它们。

## English

This Beta adapts all 14 selected upstream correctness fixes while retaining
Next's admission, quoted-file privacy, workspace, single-card, and busy-message
contracts. Stable remains v0.3.0.

- Enforce allow_from across Feishu card callbacks. Deliver current post files
  together with approved quoted attachments.
- Download file/image/audio resources with authenticated, bounded Range requests,
  strict coordinates and byte counts, cancellation, and transient retry.
- Omit --listen for Codex stdio. Discover current/legacy macOS ChatGPT/Codex CLIs,
  support CODEX_CLI_PATH, and honor explicit cmd/arguments across execution,
  workspaces, metadata and diagnostics. Invalid explicit paths fail.
- Lock idle-reset replacements before publication; retain late session IDs on
  errors and invalidate incompatible workspace IDs while preserving history.
- Keep Claude questions interactive in bypass modes and use flat card action rows.
- Discard Stop-hook-rejected draft caches. Bound inherited-pipe waits and kill
  confirmation, interrupt blocked input writes, separate user-stop grace from normal completion hooks, and fence
  overlapping close/respawn operations. Avoid automatic unsafe resume after failure.
- Restart loaded launchd services in their existing domain; display cron schedule,
  next and last execution in the task timezone.
- Remove remaining session token/context telemetry and zero-value completion logs.
  Account quota queries through /usage remain available.

Install with `npm install -g cc-connect-next@beta`, `cc-connect-next update beta`,
or chat `/upgrade beta`. Loading a running service is a separate step. npm latest
and default Stable selection remain unchanged. No new mandatory configuration or
broader Feishu permission is required. Native Windows runtime and real Feishu
mobile/large-resource end-to-end checks require separate live evidence.
