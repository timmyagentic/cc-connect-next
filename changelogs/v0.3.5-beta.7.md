# cc-connect-next v0.3.5-beta.7

## 中文

- 群聊补读支持合并/嵌套转发、图片、富文本与常见文件及音视频附件，保留发送者、时间和引用归属。
- 历史先去重并按文字预算筛选，再按数量、字节数和超时边界下载媒体；失败资源可在后续回合重试。
- 停止或撤回会取消补读准备，避免随后发送给模型；普通、排队和补处理路径保持一致。
- 新群空 sender 的系统通知正常读取；明确区分读取失败、预算限制和不可用内容。
- 仅使用既有访问权限，保持群/话题边界。未执行真实飞书消息或付费模型调用。
- Beta 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.4。

## English

- Expand merged/nested forwarded history and deliver selected images, rich posts and common file/audio/video attachments while preserving attribution.
- Deduplicate and select history before bounded media downloads; failed resources remain retryable.
- Cancel history preparation on stop/recall across foreground, queued and drain paths.
- Read senderless system events in newly created groups and distinguish read failures, budget limits and unavailable content.
- Retains existing permissions and chat/topic isolation. Live Feishu delivery and paid model calls were not exercised.
- Install with `npm install -g cc-connect-next@beta`. Stable channels remain on v0.3.4.
