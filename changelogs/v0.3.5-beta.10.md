# cc-connect-next v0.3.5-beta.10

## 中文

- `/model [名称|别名|序号]` 仅设置当前已验证私聊或群聊的模型；`/model reset` 恢复跟随默认值。
- `/model default` 查询当前机器人/项目的全局默认模型；修改默认值需要管理员权限。卡片和文本命令使用相同的权限检查。
- 默认模型变更作用于缓存的工作区及后续排队回合，不打断当前回复。需要重建后端时恢复原会话；失败时保留会话和重试信息，不静默创建新会话。
- **升级注意：** 移除旧的 `/model chat`、`/model group`、`/model switch` 命令及工作区独立默认值。旧聊天模型绑定和工作区模型设置不自动迁移，升级后请用新命令重新选择；对话历史保留。
- 修复模型命令重构留下的未使用辅助函数和测试 lint 问题。
- 本地 Web、Go 构建、lint、CUJ、smoke、regression、core/Feishu race、Node 和 Feedback Relay 验证通过。完整本地 race 测试的两项真实 Codex app-server 集成测试因环境初始化 EOF 未通过；Foundation 源码归档核对受到本地 HTTP 403 限制。发布仍须通过远端原有完整验证门禁。真实平台交互和付费模型请求未执行。
- Beta 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.4。

## English

- `/model [name|alias|number]` selects a model only for the current verified private or group chat; `/model reset` restores default inheritance.
- `/model default` inspects the current bot/project global default. Changing it requires administrator permission, shared by card and text commands.
- Changed defaults reach cached workspaces and subsequent queued turns without interrupting the current reply. Process-bound backends resume the original conversation; failed resumes retain the conversation and retry state instead of silently starting a fresh session.
- **Upgrade notice:** `/model chat`, `/model group`, `/model switch`, and independent workspace defaults are removed. Existing chat model bindings and workspace model settings are not migrated; select models again with the new commands after upgrading. Conversation history is retained.
- Remove a stale model helper and resolve test lint findings from the refactor.
- Local Web/Go builds, lint, CUJ, smoke, regression, core/Feishu race, Node, and Feedback Relay verification passed. Two real Codex app-server integration tests in the full local race suite failed with environment initialization EOF; local Foundation source-archive verification was blocked by HTTP 403. Publication remains subject to the existing complete remote validation gates. Live platform interactions and paid model requests were not exercised.
- Install with `npm install -g cc-connect-next@beta`. Stable channels remain on v0.3.4.
