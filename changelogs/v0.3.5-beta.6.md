# cc-connect-next v0.3.5-beta.6

## 中文

- 删除聊天感知推理卡片迁移后不再使用的旧包装函数，修复 beta.5 的 unused lint 失败，不改变运行行为。
- 包含私聊与群聊独立模型/推理强度、持久化与独立重置，以及飞书私聊卡片身份校验。
- 使用新的 beta tag，保留 beta.5 的不可变发布记录。稳定渠道保持 v0.3.4。
- 发布验证由此版本精确提交的 CI 与 Release 流水线执行。未执行真实飞书消息或付费模型调用。
- 安装：`npm install -g cc-connect-next@beta`；更新：`cc-connect-next update beta`。

## English

- Remove the obsolete reasoning-card wrapper after migration to the chat-aware renderer, fixing beta.5's unused lint failure without changing runtime behavior.
- Includes independent private/group model and reasoning settings, persistence, independent resets and verified private-card ownership.
- Uses a new beta tag and preserves the immutable beta.5 record. Stable channels remain on v0.3.4.
- The exact release commit is validated by CI and Release workflows. Live Feishu delivery and paid model calls were not exercised.
- Install with `npm install -g cc-connect-next@beta` or update with `cc-connect-next update beta`.
