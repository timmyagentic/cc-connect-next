# cc-connect-next v0.3.6-beta.1

## 中文

- 飞书群聊历史仅因页数、条数或文字长度截断时，不再额外发群消息；查询失败、超时，以及已选消息或附件未读全时仍提醒。
- 历史附件每轮最多 12 个资源、累计 100 MiB；分片、重试和下载共享 45 秒时限。增量附件沿用已验证的历史读取区间，修复旧图片漏读。
- 已选来源在读取中撤回时，移除其正文和已下载附件；补充视频通话状态，并保留异常分页时的可用结果。
- 网站首页加入交互聊天，并适配宽屏和手机方向；补充飞书与 Codex 同话题协作说明。
- 本地 Web 构建、发布脚本和 npm 安装器检查通过。完整 Go 验证依赖发布工作流；本地完整依赖下载受网络策略限制。真实飞书及付费模型交互未执行。
- Beta 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.5。

## English

- Keep routine Feishu history page, message and text truncation quiet. Continue reporting failed or timed-out queries and unread selected content or attachments.
- Allow up to 12 history resources and 100 MiB per turn with a shared 45-second deadline across chunks, retries and downloads. Reuse the validated incremental read window so older images are not missed.
- Remove recalled source text and downloaded attachments, read video-call metadata, and preserve usable partial results when pagination fails.
- Add interactive chat to the website hero, adapt the homepage to wide screens and phone orientations, and document same-topic Feishu/Codex collaboration.
- Local web, release-script and npm-installer checks passed. Full Go validation depends on the release workflow because local dependency downloads were restricted by network policy. Live Feishu and paid model interactions were not exercised.
- Install with `npm install -g cc-connect-next@beta`. Stable channels remain on v0.3.5.
