# cc-connect-next v0.3.5-beta.4

## 中文

### 更新亮点

- 恢复显式配置的 Provider 模型列表优先级，保留配置的顺序、别名和描述。
- Codex 模型目录和缓存按会话及 Provider 的有效配置目录解析，避免不同配置目录之间互相干扰。
- 包含此前 v0.3.5 Beta 的群模型固定和 Bridge 健康状态改进。

### 验证与使用

- 本地构建、完整测试、竞态检查和发布门禁通过；本轮未验证真实飞书消息或付费模型调用。
- 本版为 Beta，稳定渠道继续保持 v0.3.4。
- 安装：`npm install -g cc-connect-next@beta`；已有安装可执行 `cc-connect-next update beta`。

## English

### Highlights

- Restore priority for explicitly configured Provider model lists, preserving their order, aliases and descriptions.
- Resolve Codex model catalog and cache paths from the effective configuration home for each session and Provider, isolating separate configurations.
- Includes the group model pinning and Bridge health improvements from earlier v0.3.5 betas.

### Verification and usage

- Local builds, the full test suite, race checks and release gates passed. Live Feishu delivery and paid model calls were not verified in this release preparation.
- This is a beta release; stable channels remain on v0.3.4.
- Install with `npm install -g cc-connect-next@beta` or update with `cc-connect-next update beta`.
