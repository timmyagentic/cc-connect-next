# cc-connect-next v0.3.6-beta.5

## 中文

- 修复 beta.4 回归测试的空临界区静态检查问题，保持等待补送结束的同步语义；运行时行为不变。

- 修复普通补充消息在模型绑定、推理强度、临时回答档位或默认配置变化后无法追加到当前回合的问题。普通补充继承当前回合的实际参数，新默认值在下一独立回合生效。
- 启动期间的补充消息在 Agent 就绪后按顺序补送，保留图片与文件；等待追加与确认成功分别显示，未知结果避免重复投递。
- 修复较晚追加导致已接受排队任务丢失、延迟卡片交接恢复旧发送者身份，以及普通补充进入定时任务的问题。补送不会阻塞事件读取，撤回与回合切换约束补送目标。
- 详见 [PR #217](https://github.com/timmyagentic/cc-connect-next/pull/217)。真实飞书群和运行中 daemon 更新未在本次发布中实测。
- 安装：`npm install -g cc-connect-next@beta`。稳定渠道保持 v0.3.5。

## English

- Fix beta.4 static analysis by reading the regression-test snapshot inside the synchronization barrier, preserving its delivery-settlement guarantee without changing runtime behavior.

- Allow ordinary follow-ups to steer into the active turn with model bindings, reasoning effort, temporary answer profiles and changed defaults. Follow-ups inherit active-turn options; new defaults apply to the next independent turn.
- Deliver startup supplements in order once the Agent is ready, preserving images and files. Distinguish pending from confirmed delivery and avoid duplicate delivery when the outcome is unknown.
- Preserve accepted queued tasks and current sender authorization across later steering and delayed card handoffs. Keep scheduled turns separate, continue consuming events during delivery, and respect recalls and turn transitions.
- See [PR #217](https://github.com/timmyagentic/cc-connect-next/pull/217). Live Feishu groups and running daemon upgrades were not exercised during this release.
- Install with `npm install -g cc-connect-next@beta`. Stable remains v0.3.5.
