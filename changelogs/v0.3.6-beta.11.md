# cc-connect-next v0.3.6-beta.11

## 中文

- 飞书卡片支持通过 `hook:<name>` 触发本机配置的命令或 HTTP 处理器。按钮动作、操作者、卡片路由、业务数据和最终表单值通过 `card.action` 事件传递。
- Hook 配置新增 `name`、`project` 和命令 `input = "json"`，复用现有超时、执行器与 HTTP JSON。卡片处理器按项目和名称精确匹配，接受后异步执行并返回处理中提示。处理器负责操作结果、幂等和恢复。
- 本地验证覆盖命名路由、表单原文、普通按钮、权限、慢处理器和既有卡片兼容。发布流水线执行完整验证。真实飞书回调与运行中 daemon 切换在安装后验收。
- 安装 `npm install -g cc-connect-next@beta`。

## English

- Feishu card buttons can select a locally configured command or HTTP handler with `hook:<name>`. The `card.action` event carries the action, operator, card route, opaque data and submitted form values.
- Hook configuration adds `name`, `project` and command `input = "json"`, reusing existing executors, timeouts and HTTP JSON. Card handlers match an explicit project and name and run asynchronously after acceptance. Handlers own operation outcomes, idempotency and recovery.
- Local checks cover named routing, exact form values, ordinary buttons, admission, slow handlers and existing cards. The release pipeline performs full validation. Live callbacks and daemon migration are verified after installation.
- Install with `npm install -g cc-connect-next@beta`.
