# v0.3.7-beta.3

## English

- Add the opt-in `scheduled.progress` hook for Cron and Timer runs (#244).
- Events carry execution phase, timing and anonymous counts. Publishing is asynchronous and coalesced; prompts, tool arguments and response content are excluded.
- A finished event indicates execution ended, not that business validation or delivery succeeded.

## 中文

- 为 Cron 和 Timer 新增显式启用的 `scheduled.progress` 进度 Hook（#244）。
- 事件包含执行阶段、耗时及匿名计数，异步合并发送，不包含提示词、工具参数或回复正文。
- 终态表示执行结束，不代表业务校验或通知送达成功。
